MSIX is a modern Windows packaging format. This guide outlines the high-level workflow and where MSIX fits into the Wails packaging pipeline.

## When to use MSIX

- You want a modern installer/update experience on Windows.
- You need store-friendly packaging constraints.

## Typical workflow

- Configure your build assets and packaging settings.
- Build your application.
- Produce an MSIX package as part of your Windows packaging process.
