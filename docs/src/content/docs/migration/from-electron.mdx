This guide highlights common migration considerations when moving from an Electron app to Wails v3.

## What changes

- **Backend runtime**: Node.js main process → **Go application**.
- **IPC**: Electron IPC → **Wails bindings/events**.
- **Packaging**: Electron builders → **Wails build + platform packaging**.

## Typical migration plan

- Keep your existing frontend (React/Vue/etc.) and wire it into Wails.
- Move business logic out of the Electron main process into Go services.
- Replace IPC calls with bindings (request/response) and events (pub/sub).
